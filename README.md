# Сайт SpecMate AI

Статичный сайт: index.html + папка img. Публикуется на GitHub Pages.

- Логотип встроен в index.html (SVG), значок вкладки — favicon.svg.
- Яндекс.Метрика: вставьте код счётчика в <head> на место комментария
  и добавьте после него строку <script>window.YM_ID = НОМЕР_СЧЁТЧИКА;</script> —
  тогда клики по карточкам «демо / пилот / вопрос» будут считаться целями demo, pilot, question.
